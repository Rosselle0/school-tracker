# School

A board for the classes you still have. Open the site, sign in with Google, pick your school, and add classes by code or by dropping a picture or PDF.

Signing in with the same Google account opens the same university, classes, notes, and wallpaper on a phone or another computer. Someone else who signs in gets their own board. Settings can delete that tracker account without deleting the Google account.
